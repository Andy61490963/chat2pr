## 新增或修改文件

- 使用繁體中文。發現新的潛規則就補進 [專案慣例與注意事項](conventions.md)，附上原因。
- 改了指令、路徑或設定名稱時，搜尋 `README.md` 與 `docs/` 所有出現處一起更新。
- 文件與測試只用虛構的專案、群組與帳號名稱（例如 `example-org/OrderService`），不放真實客戶資訊與機密。
