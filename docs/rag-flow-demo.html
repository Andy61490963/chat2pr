從訊息到可審閱的成果

RAG 流程驗收

收訊 → 檢索 → 開發 → 審查 → PR

  1. 01

    收訊

    收到群組訊息，整理這次需要完成的事情。

  2. 02

    檢索

    查找專案文件與過往經驗，作為本次工作的參考。可參考同群組歷史討論、專案檔案與過往任務結果。

  3. 03

    開發

    依照本次核准範圍修改程式，並執行測試。

  4. 04

    審查

    檢查變更與驗證結果，確認符合本次需求。

  5. 05

    PR

    整理變更說明並提出合併請求，交由人工確認。

靜態流程展示・過往經驗僅供參考，執行以本次核准需求為準。
正式群組可追溯需求來源，PR 完成後由管理者確認合併。
