02　LINE 官方帳號

每台伺服器使用自己的 Messaging API channel；一個 channel 只能設定一個 Webhook 網址，不能與其他伺服器共用。

開啟 LINE Developers ↗

在 Messaging API 頁面設定 Webhook、啟用 Use webhook 與 Allow bot to join group chats。關閉不需要的自動回應，避免干擾群組。

03　固定 HTTPS 入口

外界只經過這個入口連到看板與 Webhook。三種方式擇一；儲存後要重新啟動主機程序才會換用新的入口。

登入 ngrok，取得固定開發網址 ↗

開啟 Cloudflare Zero Trust，建立通道 ↗

在 Networks → Tunnels 建立通道，公開主機名稱的服務填 http://127.0.0.1:4310。這台主機要先安裝 cloudflared（winget install Cloudflare.cloudflared）。

用 cloudflared tunnel create 建立的通道填設定檔路徑；兩者都有時使用通道權杖。

入口由你自己的程序維護：把流量轉到 http://127.0.0.1:4310，並定時更新 .local/tunnel-status.json。條件見 README〈外部帳號設定〉。

只填網址，不加 /webhooks/line。
