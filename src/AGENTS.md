# 看板介面規則

- 修改頁面前先查 `src/components/ui/` 和[設計系統](../docs/design-system.md)。同一用途重用同一元件。需要新尺寸或狀態時，在原元件新增變體。
- 顏色、字級、行高、間距、圓角、陰影與焦點框取自 `src/styles.css`。頁面使用具名工具類別。版面需要新的固定值時，先檢查現有代幣是否適用。
- 維持 Industrial MES 的資訊密度。明細用鍵值列，列表用細邊框分隔。一個畫面只有一個主要動作使用運轉綠。頁首至多 20px，內文 14px，圓角至多 6px。浮層才用陰影，禁用漸層與毛玻璃。
- 保留控制項的可達名稱、鍵盤操作、焦點還原與 375px 觸控區。數字使用 `tabular-nums`。
- 新增或修改共用元件時，一起更新 `docs/design-system.md`、`e2e/design-system-gallery.tsx` 與展示截圖，檢查 375px、1440px 的深淺色。
- CI 會攔截新增的任意值、固定行內像素、大圓角與禁用效果。遷移完成後刪除對應的既有基準列。基準只可刪減。
